# SQL Analysis Guide

## Overview

MySQL was used to analyze the supply chain dataset and answer business questions across four major areas.

## 1. Executive Analysis

The executive analysis focuses on overall business performance.

Key areas include:

- Total Sales
- Total Profit
- Total Orders
- Average Order Value
- Monthly Sales Trends
- Market Performance

## 2. Sales & Customer Analysis

This analysis evaluates sales performance and customer behavior.

Key areas include:

- Sales by customer segment
- Top customers
- Sales by market
- Average order value
- Monthly sales performance
- Customer purchasing behavior

## 3. Product Analysis

This analysis evaluates product and category performance.

Key areas include:

- Best-selling products
- Product quantity sold
- Product sales
- Product profitability
- Category performance
- Top products within categories

## 4. Supply Chain & Logistics Analysis

This analysis evaluates delivery and shipping performance.

Key areas include:

- Delivery performance
- Late-delivery rate
- Shipping mode performance
- Delivery time
- Scheduled vs actual delivery time
- Late deliveries by market
- Late deliveries by region

## SQL Techniques Used

The analysis uses MySQL techniques including:

- SELECT
- WHERE
- GROUP BY
- ORDER BY
- JOIN
- COUNT
- SUM
- AVG
- ROUND
- CASE
- DISTINCT
- Common Table Expressions
- Window functions such as LAG()
- Percentage calculations

## Purpose

The SQL analysis transforms raw supply chain data into business insights that can be used by management to evaluate performance and make informed decisions.
